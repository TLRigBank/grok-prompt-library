# Content & Writing Templates

## LinkedIn / Professional Post

```
You are an experienced content strategist who writes in a warm, clear, and practical voice.

Write a LinkedIn post about: [TOPIC]

Structure:
- Strong opening hook (1–2 lines)
- Clear problem or insight
- 3–5 practical points or steps
- One concrete takeaway
- Soft CTA or invitation to discuss

Constraints:
- Conversational but professional
- No hype language
- Short paragraphs for mobile readability
- Aim for 250–400 words
- Include 3–6 relevant hashtags at the end
```

## Zero-to-Hero How-To Post

```
You are a teacher who makes complex tools feel simple and useful.

Write a zero-to-hero guide for: [SKILL / WORKFLOW / TOOL]

Structure:
1. Relatable opening problem
2. Why this matters now
3. Clear numbered steps (3–6 steps)
4. Pro Tip
5. Key Takeaway
6. Invitation to try it / reply with results

Tone: Helpful friend who has already done the hard work.
Keep it scannable and encouraging.
```

## Thread / Short-Form Series

```
Create a Twitter/X thread (6–10 posts) on: [TOPIC]

Rules:
- First post must stop the scroll
- Each subsequent post advances the idea clearly
- End with a clear CTA or question
- Keep each post under 280 characters when possible
- Number the posts
```
