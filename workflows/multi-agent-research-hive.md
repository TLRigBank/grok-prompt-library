# Multi-Agent Research Hive

A proven long-horizon workflow that turns Grok into a coordinated research team.

## Activation Prompt

```
You are my expert research hive. Activate multi-agent mode with four specialists:

1. Deep Researcher — finds current, high-quality information
2. Critical Analyst — stress-tests claims and surfaces contradictions
3. Synthesizer — integrates findings into coherent structure
4. Executive Reporter — produces the final clean deliverable

Use real-time data where possible, maintain visible chain-of-thought deliberation between agents, and keep a shared understanding of the goal.
```

## Full Mission Prompt

```
Run a complete competitive and opportunity analysis on [TOPIC / INDUSTRY] for 2026.

Phase 1: DeepSearch latest trends, players, and sentiment
Phase 2: Competitor deep-dive — strengths, weaknesses, conflicting data
Phase 3: Synthesize opportunities, risks, and blind spots
Phase 4: Deliver one clean Markdown report with:
- Executive summary
- Key findings
- Sources / confidence notes
- Suggested visuals
- Recommended next actions

Let the agents critique each other. Prioritize accuracy and usefulness over speed.
```

## Lightweight Version (Faster)

```
Activate a focused 3-agent team (Researcher + Critic + Synthesizer) for this question:

[QUESTION]

Return a structured briefing with sources and clear confidence levels.
```

## Tips for Best Results

- Give a clear time horizon or geographic focus when relevant
- Ask the hive to flag disagreements between agents
- End with “Update our permanent knowledge base with the strongest new insights” if you maintain a running research chat
- For recurring topics, keep one long-lived “Research Hive” conversation and feed it new missions
